Subject: New asset_type_totals field on both "All Vulnerabilities" APIs

Dono endpoints ab ek naya top-level field return karte hain:


GET /api/admin/adminasset/report/<report_id>/vulnerabilities/
GET /api/user/asset/report/<report_id>/vulnerabilities/
Response shape (naya field highlighted):


{
    "report_id": "6aab98af8deb6d77d9751632",
    "total": 5,
    "asset_type_totals": {
        "other": 49,
        "web_app": 0,
        "firewall": 0,
        "server": 0
    },
    "vulnerabilities": [ ... unchanged ... ]
}
Isse kaise use karna hai: "All Vulnerabilities" page ke top pe jo "Assets / Web App / Firewall / Server" filter tabs hain, unke pass ab ek overall/report-level count badge dikha sakte ho (jaise "Assets (49)") — bina har vulnerability ke asset_type_counts ko manually loop-sum kiye. Yeh number already correctly deduped hai (ek asset ek hi baar count hota hai, chahe uski multiple vulnerabilities ho) — isliye is field ko seedha use karo, khud se sum mat nikalna.

User-side (/api/user/asset/...) me yeh count sirf us member ki apni team se relevant assets tak scoped hai — admin ke poore-report wale number se alag ho sakta hai, yeh expected/correct hai.

Koi backward-incompatible change nahi hai — vulnerabilities array aur baaki fields bilkul waise hi hain, sirf yeh ek naya field add hua hai.
