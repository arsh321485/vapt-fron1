2. Priority logic (in AutomatedFixPanel.vue and any "Automatable" badge check)

if card.automation_card && card.automation_card.automation_status in ("full", "partial"):
    → show AI-generated content (this is the primary path now — covers every vuln)
elif card.automation_card && card.automation_card.automation_status == "not_possible":
    → show "Automation not possible" + card.automation_card.reason_not_possible
elif card has a plugin_id:
    → fall back to existing curated match/{plugin_id}/ lookup (legacy ~129-plugin coverage)
else:
    → "No automated fix available"
