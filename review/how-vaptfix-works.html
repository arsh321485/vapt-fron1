VAPTFIX Onboarding

Three Ways to Access

Choose your entry point — Email, Slack, or Microsoft Teams. All three follow the same onboarding journey.

Product flow

From a finding to a verified fix

Four steps. The model writes the plan. A person approves it before anything runs. The plan stays on record with the finding it came from and the model that wrote it.

From Sign-Up to Full Access

Company Email. Admin signs up directly on the VAPTFIX website using their company email address and a password. Five clear steps take the admin from registration to full dashboard access.

01

Sign-Up & Sign-In

Admin arrives at the VAPTFIX website and clicks "Get Started." Enters company email, sets a password and confirms it, then signs in. At this stage also, the admin can choose a plan based on their requirements before proceeding to the Upload Report page.

02

Report Submission

Admin chooses one of two paths to get a VA report into the system:

Path A — Upload Existing Report

Admin uploads an existing VA report on the website. Accepted today: Nessus files, AWS Security Hub exports, and custom assessment files. There is no separate live connector for other scanners. The system reads the assets in the file and sets the plan from that count.

NessusAWS Security HubCustom assessment
OR
Path B — Provide Scope

Admin provides the required scope by entering the IP ranges/assets, and they are then assessed using Nessus or equivalent tools. The generated report is uploaded into the backend. The applicable plan is determined based on the total number of IPs/assets provided in the scope.

Internal IPExternal IPWeb AppMobile App
03

Add Users

Admin lands on the Add Users page and adds users to the workspace. The teams visible are based on the selected plan. On Freemium, only the team with the maximum number of assets is visible; Premium and Enterprise provide access to all four teams.

Network SecurityConfiguration ManagementArchitecture FlawPatch Management
04

Risk Criteria

Admin lands on the Risk Criteria page and completes a one-time setup defining four risk criteria: Critical, High, Medium, and Low.

CriticalHighMediumLow
05

Onboarding Complete

Once risk criteria are submitted, the admin is fully onboarded and can begin using VAPTFIX — dashboard, vulnerability tracking, fix management, and team collaboration are all live.

Slack Onboarding Flow

The Slack journey follows the same onboarding logic, delivered through interactive Slack cards within the workspace.

S

Slack Marketplace: in review

Sign up with Slack and run remediation from cards in the workspace: assign a finding, approve a step, and close it with the audit record attached. The Slack app is available for that workflow. The Slack Marketplace listing is in review.

Connect your Slack workspace

Already have a Slack workspace? Skip steps 5 and 6.

03

Enter Email Slack

04

Verify Code Slack

06

Close Slack Window SlackNew users only

Sign up with Slack Again VAPTFIX

In the Get Started modal, click Sign up with Slack once more.

08

Select & Allow Slack

Select your workspace and click Allow to install the VAPTFIX app.

09

Verify Code Again Slack

Enter the new 6-digit code Slack emails you to confirm the install.

10

Part 2

Onboard inside Slack

01

Welcome Card

VAPTFIX posts a Welcome Card in the Slack workspace confirming the Admin role. The admin is then prompted to begin onboarding by uploading a VA report or providing the required scope.

02

Report Submission

Path A — Upload Report Card

Admin uploads an existing VA report directly in Slack. Accepted today: Nessus files, AWS Security Hub exports, and custom assessment files. There is no separate live connector for other scanners.

NessusAWS Security HubCustom assessment
OR
Path B — Provide Scope Card

Enter Internal assets, External assets, Web Apps, and Mobile Apps directly in the Slack card. VAPTFIX runs the scans and uploads the report to the backend.

Internal IPExternal IPWeb AppMobile App
03

Plan Limit Check Conditional

If the selected plan's limits are exceeded, the Plan Limit Card will appear automatically in Slack. The Admin can either upgrade to Premium/Enterprise, which redirects to the VAPTFIX website, or adjust the scope to remain within the selected plan's limits.

04

Add Users Card

Admin adds team members directly from Slack. The teams visible are based on the selected plan. On Freemium, only the team with the maximum number of assets is visible; Premium and Enterprise provide access to all four teams.

Network SecurityConfiguration ManagementArchitecture FlawPatch Management
05

Risk Criteria Form

A one-time fillable form opens to define four risk criteria: Critical, High, Medium, and Low. These criteria establish the organisation’s vulnerability scoring baseline.

CriticalHighMediumLow
06

Workspace Set Up

Once the risk criteria are submitted, the workspace is fully set up. A final Slack card confirms onboarding is complete and provides a link to the live VAPTFIX dashboard.

07

Onboarding Complete

A final Slack card confirms your workspace is fully set up. A link to the live VAPTFIX dashboard is provided directly in the card.

Part 3

Offboard: remove VAPTFIX from Slack

Uninstalling only disconnects Slack. Your VAPTFIX data stays safe unless you confirm deletion from the email.

01

Open Admin Tools Slack

In Slack, click Admin in the sidebar and open Apps & workflows.

02

Find VAPTFIX Slack

Under Installed apps, click ••• next to VAPTFIX and choose Uninstall.

03

Confirm Uninstall Slack

Tick "I want to uninstall VAPTFIX from my team" and click Uninstall.

04

Removal Email Email

VAPTFIX emails you that Slack is disconnected. Your data is still safe.

05

Delete Account EmailOptional

Click the delete button within 48 hours to erase your account. This cannot be undone.

06

Deletion Confirmed VAPTFIX

A page confirms your VAPTFIX account and all its data are permanently deleted.
